# Historical v26 and NeurIPS development archive

This subtree preserves the retired v26 implementation, development configs,
logs, result tables, anonymous supplement, and prior NeurIPS manuscript exactly
as historical development evidence. It is not part of the supported MaskImpute
API or the Genome Biology evidence pipeline.

Files here may use superseded scientific terminology and may reflect analyses
that informed method development. Publication runners must consume only the
canonical `maskimpute` package, the active benchmark package, and sealed study
assets. They must never import code or numerical claims from this subtree.

The root-level `masked_imputation26.py` file is migration guidance only. The
preserved executable source is in `code/masked_imputation26.py`.
